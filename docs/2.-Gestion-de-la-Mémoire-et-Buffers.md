# 2. Gestion de la Mémoire et des Buffers (VRAM)

Pour surpasser les goulots d'étranglement de la bande passante CPU-GPU (liaison PCIe) et gérer les limites physiques de la VRAM (Memory Wall), GPUsync implémente un système d'allocation et de transfert asynchrone explicite via la classe `AsyncBuffer`, couplé au streaming **Out-Of-Core monoligne** et à l'interopérabilité **DLPack Zero-Copy**.

---

## La classe `AsyncBuffer`

`AsyncBuffer` représente un tableau de données résidant physiquement en mémoire GPU (VRAM).
- **En OpenCL** : Encapsule un objet `pyopencl.Buffer`.
- **En CUDA** : Encapsule un objet `cupy.ndarray` associé à un contexte CUDA précis.
- **En LLVM CPU** : Encapsule un objet `numpy.ndarray` contigu en RAM.

### Méthodes clés :
- **`AsyncBuffer.to_device(scheduler, host_data)`** : Alloue la mémoire sur la carte et y copie les données CPU de façon asynchrone.
- **`AsyncBuffer.empty_like(scheduler, host_data)`** : Pré-alloue un espace mémoire vide en VRAM.
- **`to_host()`** : Rapatrie les données VRAM vers la mémoire RAM hôte sous forme de tableau NumPy.
- **`__dlpack__(stream=None)`** : Exporte la mémoire sous forme de PyCapsule DLPack pour un partage Zero-Copy avec PyTorch et CuPy.
- **`AsyncBuffer.from_dlpack(dlpack_obj, scheduler)`** : Importe un tenseur PyTorch/CuPy sans aucune copie mémoire.

## Traitement Out-Of-Core Monoligne (`map_out_of_core`)

Pour traiter des jeux de données géants (ex: 50 Go, 500 Go) dépassant la taille de la VRAM, GPUsync propose l'API `kernel.map_out_of_core()` :

```python
# 1. Avec un tableau NumPy géant en RAM
resultat = process_signal.map_out_of_core(large_dataset, scheduler=sched)

# 2. Avec un GÉNÉRATEUR DISQUE (NVMe SSD -> RAM -> PCIe -> VRAM -> GPU)
def stream_fichier_disque(filepath):
    with open(filepath, "rb") as f:
        while True:
            chunk = np.fromfile(f, dtype=np.float32, count=1_000_000)
            if len(chunk) == 0: break
            yield chunk

resultat = process_signal.map_out_of_core(stream_fichier_disque, scheduler=sched)
```

### Avantages :
- **Régulation par sémaphore asynchrone** (`concurrency=2` par défaut).
- **Zero OOM VRAM** : Découpe automatique du dataset en blocs.
- **Concaténation transparente** des résultats finaux.

## Transfert Automatique Inter-GPU (Pipelines)

Dans le cadre d'un algorithme multi-GPU complexe (défini par `@gpusync_pipeline` avec un `MultiDeviceScheduler`), GPUsync compare le `device_manager` cible du kernel avec celui de chacun des buffers d'entrée pour effectuer les transferts croisés automatiquement via le bus PCIe.
